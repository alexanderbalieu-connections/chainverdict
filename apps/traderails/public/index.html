ChainVerdict / TradeRails

Check trade and logistics identifiers.

Validate barcodes, container numbers and vessel identifiers, or get candidate customs headings from a goods description.

Routes and prices

Prices are in USDC per request. The current x402 quote is returned with HTTP 402. Format checks do not verify ownership. Customs heading suggestions are a starting point for review.

API referenceAgent guidex402 discovery

GET /v1/gtin/validate?code=
Validate GTIN-8/12/13/14, UPC-A, EAN-13 — check digit, format, GTIN-14, packaging indicator.		0.004
GET /v1/gtin/checkdigit?body=
Compute the GS1 check digit for a code body that is missing it.		0.004
GET /v1/gtin/prefix?code=
GS1 Member Organisation for a prefix. (Numbering org — not country of origin.)		0.004
GET /v1/sscc/validate?code=
SSCC-18 logistics-unit serial shipping container code.		0.004
GET /v1/container/validate?code=
ISO 6346 shipping container number — owner, category, serial, check digit.		0.004
GET /v1/imo/validate?code=
IMO ship identification number check digit.		0.004
GET /v1/gs1/decode?data=
Decode a GS1 element string / GS1-128 (GTIN, batch, expiry, serial, weight). Human (01)…(17)… or raw FNC1.		0.006
POST /v1/gs1/decode
Decode a GS1 element string from a JSON request body.		0.006
GET /v1/hs/classify?q=
HS-code triage: ranked candidate headings + official text + GRI note. Informational, not a customs ruling.		0.05
