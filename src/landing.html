Call it in 30 seconds

Any x402 client works. With x402-fetch and a funded Base wallet:

import { wrapFetchWithPayment } from "x402-fetch";
const payFetch = wrapFetchWithPayment(fetch, account);
const res = await payFetch(
  "https://chainverdict.xyz/v1/token/verdict/0x4200000000000000000000000000000000000006"
);
console.log(await res.json()); // → verdict, score, reasons
