Small checks, on demand

Ask. Pay for the check.
Read the evidence.

An API is a way for one piece of software to ask another for information. ChainVerdict is designed for developers and AI agents—software that can carry out tasks on someone’s behalf.

x402 lets that software pay for a single request. Payments use USDC on Base. You do not need a ChainVerdict account, but paid calls need a compatible client and a funded wallet.

  1. Choose a check.Send a token, wallet, transaction or supported input.
  2. Receive a price.The service quotes the cost before the paid response.
  3. Get the result and its sources.Your software pays and receives structured data, with freshness and limitations.
  4. Keep control of the decision.ChainVerdict reports observations. Your application decides what to do next.

Evidence, with boundaries

Useful facts.
No blanket “safe” stamp.

A checksum can show that a number is correctly formed. It cannot show that an account exists. A signature can show that a response has not been altered. It cannot make the answer true.

Every check explains its method and limits. You can read the methodology or verify a signed response without paying.

Repeatable checksNamed rules and data sources, rather than an unexplained opinion.
Freshness includedSee when the information was observed. Cached data can become stale.
Limitations includedA result is informational. It is not financial advice, a security audit or a compliance approval.

Current limitation: historical Pulse archive. Records for 56 days between 7 August and 1 October 2026 do not match their stored fingerprints. This history remains disclosed as unverifiable; acknowledging it does not repair it. Read the live integrity report ↗

Automatic purchases that refreshed our own attestations are off. Check the date on any cached attestation before using it.
